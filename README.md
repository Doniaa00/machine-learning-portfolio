# Machine Learning Case Studies

A collection of end-to-end machine learning projects, each including data exploration, model building, evaluation, and a full report with business-oriented insights.

## Project Overview

This repository contains applied machine learning case studies built from real-world datasets, covering the full workflow from data cleaning and exploratory analysis to model evaluation and final deliverables (reports and presentations).

## Projects Included

1. **Heart Disease Prediction** — End-to-end analysis to predict cardiovascular disease risk using patient clinical data, including EDA, a tuned Random Forest model, and a full written report.
2. **Customer Segmentation** — Complete end-to-end analysis using K-Means clustering for market segmentation, with business recommendations and a presentation deck.

## Technologies Used

- Python 3.10+
- pandas, numpy for data manipulation
- scikit-learn for machine learning
- matplotlib, seaborn for visualization
- Jupyter Notebooks for interactive development
